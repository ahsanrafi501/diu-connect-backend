# DIU Connect Backend

DIU Connect is a software engineering final-year project for the Daffodil International University community. It connects students, alumni, and faculty around collaboration projects and career opportunities.

This repository starts with project documentation and Git configuration. The backend uses TypeScript, Express, Prisma, PostgreSQL, and Redis. The frontend will have its own repository.

## Run the API

Use Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

Open `http://localhost:4000/health` to check that the HTTP process responds.
Set the `PORT` environment variable to use another port.
